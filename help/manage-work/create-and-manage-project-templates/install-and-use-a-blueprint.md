# Instalar e usar um Blueprint

Saiba como um administrador instala um blueprint e como um usuário o coloca em uso. Neste exemplo, instalaremos o blueprint &quot;Treinamento do Workfront para novos usuários&quot; e usaremos os modelos e as visualizações que ele cria como uma lista de verificação de treinamento para ajudar a habilitar usuários no Workfront.


>[!VIDEO](https://video.tv.adobe.com/v/3479833/?quality=12&learn=on&enablevpops=0)

## Principais lições

* Como selecionar um blueprint e determinar se ele já foi instalado ou não. Isso pode ser feito pela maioria dos usuários com uma licença Standard.
* Como instalar um blueprint e compartilhar os objetos criados por ele. Isso requer os serviços de um administrador do sistema.
* Como localizar e usar novos modelos de projeto criados pela instalação de um blueprint.
